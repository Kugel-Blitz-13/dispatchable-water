# Aquaspot · market finder for desalination

Team Sea Major · MIT Energy & Climate Hack 2026 · Harmony Desalting challenge.

A single-page decision tool for the desalination industry: score any location on environmental, political and economic uncertainty, set your own priorities, pick a region, and read what kind of plant fits, how urgent it is, how big it should be, and who to sell it to.

- `index.html` — the dashboard, self-contained (no build step; fonts from Google Fonts).
- `pitch-deck.pdf` — the nine-slide submission deck.

Prototype: every variable is a 0–100 rank hand-scored for 38 places from public sources (WRI Aqueduct, NASA GRACE, JRC WAD, WEF Nexus Index, CCVI, UNU, Oregon State TFDD, World Bank). Not a live feed.
